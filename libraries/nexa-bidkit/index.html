nexa-bidkit

Day-ahead and intraday auction bid generation for European power markets.

Day-ahead and intraday auction bid generation library for European power markets. Type-safe EUPHEMIA bid modelling with Nord Pool serialisation and pre-submission validation.

Python 3.11+ MIT License v1.0.0 

pip install nexa-bidkit

GitHub | PyPI

Why this exists

Building bids for European power auctions is complex. EUPHEMIA supports block bids, linked orders, exclusive groups, and merit-order curves, each with specific constraints that vary by exchange. Getting the domain model wrong means rejected bids or unintended market exposure.

nexa-bidkit provides:

  • Type-safe bid construction via Pydantic v2 models with strict validation
  • DataFrame-first API for building merit-order curves from pandas DataFrames
  • 15-minute MTU support natively across all bid types (hourly and quarter-hourly)
  • EUPHEMIA-compatible output including block, linked, indivisible, and exclusive bids
  • Nord Pool serialisation converting order books to Nord Pool Auction API payloads
  • Pre-submission validation catching EUPHEMIA violations, data quality issues, and temporal constraints

Quick start

Build a merit-order curve from a DataFrame

import pandas as pd
from decimal import Decimal
from datetime import datetime
from zoneinfo import ZoneInfo
from nexa_bidkit import (
    CurveType,
    MTUDuration,
    MTUInterval,
    from_dataframe,
)

# Your bid data as a DataFrame
df = pd.DataFrame({
    "price": [10.5, 25.0, 45.0, 80.0],
    "volume": [50, 100, 75, 25],
})

# Define the MTU this curve applies to
mtu = MTUInterval.from_start(
    datetime(2026, 4, 1, 13, 0, tzinfo=ZoneInfo("Europe/Oslo")),
    MTUDuration.QUARTER_HOURLY,
)

# Convert to a validated supply curve
curve = from_dataframe(df, curve_type=CurveType.SUPPLY, mtu=mtu)

print(f"Total volume: {curve.total_volume} MW")
print(f"Price range: {curve.min_price} - {curve.max_price} EUR/MWh")

Create block bids

from decimal import Decimal
from datetime import datetime
from zoneinfo import ZoneInfo
from nexa_bidkit import (
    BiddingZone,
    Direction,
    DeliveryPeriod,
    MTUDuration,
    block_bid,
    indivisible_block_bid,
    linked_block_bid,
    exclusive_group,
)

delivery = DeliveryPeriod(
    start=datetime(2026, 4, 1, 10, 0, tzinfo=ZoneInfo("Europe/Oslo")),
    end=datetime(2026, 4, 1, 14, 0, tzinfo=ZoneInfo("Europe/Oslo")),
    duration=MTUDuration.QUARTER_HOURLY,
)

# Partially fillable block bid (50%+ fill accepted)
peak_bid = block_bid(
    bidding_zone=BiddingZone.NO1,
    direction=Direction.SELL,
    delivery_period=delivery,
    price=Decimal("55.0"),
    volume=Decimal("100"),
    min_acceptance_ratio=Decimal("0.5"),
)

# Must-run: all-or-nothing
must_run = indivisible_block_bid(
    bidding_zone=BiddingZone.NO1,
    direction=Direction.SELL,
    delivery_period=delivery,
    price=Decimal("25.0"),
    volume=Decimal("50"),
)

# Linked bid: only accepted if must_run is accepted
ramp_up = linked_block_bid(
    parent_bid_id=must_run.bid_id,
    bidding_zone=BiddingZone.NO1,
    direction=Direction.SELL,
    delivery_period=delivery,
    price=Decimal("35.0"),
    volume=Decimal("25"),
)

Manage an order book and validate

from nexa_bidkit import (
    create_order_book,
    add_bid,
    add_bids,
    total_volume_by_zone,
    orders_to_dataframe,
    validate_order_book_for_submission,
    BidStatus,
)

book = create_order_book()
book = add_bid(book, must_run)
book = add_bids(book, [peak_bid, ramp_up])

volumes = total_volume_by_zone(book)
print(f"NO1 volume: {volumes[BiddingZone.NO1]} MW")

# Validate before gate closure
gate_closure = datetime(2026, 3, 31, 12, 0, tzinfo=ZoneInfo("Europe/Oslo"))
validate_order_book_for_submission(book, gate_closure_time=gate_closure)

# Export to pandas for review
df = orders_to_dataframe(book)
print(df[["bid_id", "bid_type", "bidding_zone", "status"]])

Serialise to Nord Pool

from nexa_bidkit.nordpool import order_book_to_nord_pool

# Map (MTUInterval, BiddingZone) to Nord Pool contract IDs
# Populate this from Nord Pool's products API at runtime
def resolve_contract(mtu, zone):
    return f"{zone.value}-{mtu.start.hour}"

submission = order_book_to_nord_pool(
    book,
    auction_id="DA-2026-04-01",
    portfolio="my-portfolio",
    contract_id_resolver=resolve_contract,
)

print(f"Curve orders:        {len(submission.curve_orders)}")
print(f"Block orders:        {len(submission.block_orders)}")
print(f"Linked block orders: {len(submission.linked_block_orders)}")

Supported bid types

Bid Type Description Supported
Simple bids Price-quantity curves per MTU (hourly or 15-min) Yes
Block bids Fixed price/volume across consecutive MTUs, partially fillable Yes
Indivisible block bids All-or-nothing block bids Yes
Linked block bids Acceptance depends on parent bid Yes
Exclusive groups At most one bid in the group accepted Yes

Validation

The validation module enforces rules before submission:

  • EUPHEMIA rules: Maximum 200 curve steps per MTU; block duration limits (1-24 hours)
  • Data quality: Minimum volume 0.1 MW; reasonable price increments
  • Temporal constraints: Gate closure deadlines; delivery periods within auction day
  • Portfolio limits: Volume sanity checks across bidding zones
from nexa_bidkit import validate_bids, get_validation_summary

results = validate_bids([must_run, peak_bid, ramp_up])
summary = get_validation_summary(results)

print(f"Validated {summary['total_bids']} bids")
print(f"Pass rate: {summary['pass_rate']:.1f}%")

Key concepts

Market Time Units (MTU)

EU power markets transitioned to 15-minute MTUs on 30 September 2025. The library handles both:

  • MTUDuration.QUARTER_HOURLY — 15-minute intervals (96 per day)
  • MTUDuration.HOURLY — hourly intervals (24 per day)

Prices and volumes use Decimal

All prices and volumes are decimal.Decimal. This avoids floating-point rounding errors in bid calculations, which matter when prices differ by 0.01 EUR/MWh.

Nord Pool serialisation

The nexa_bidkit.nordpool module converts order books to Nord Pool Auction API request payloads. You supply a ContractIdResolver callable that maps (MTUInterval, BiddingZone) to Nord Pool contract IDs. Call Nord Pool's products API to populate this lookup at runtime.
