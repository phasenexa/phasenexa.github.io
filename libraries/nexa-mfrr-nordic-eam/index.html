nexa-mfrr-nordic-eam

Build, validate, and serialise mFRR energy activation market bids for the Nordic TSOs.

Python library for building, validating, and serialising mFRR energy activation market (EAM) bids for the Nordic TSOs: Statnett (NO), Energinet (DK), Svenska kraftnät (SE), and Fingrid (FI).

What it does

The Nordic mFRR energy activation market (EAM) went live on 4 March 2025 as part of the Nordic Balancing Model (NBM). BSPs submit bids via ECP/EDX as CIM XML documents to their connecting TSO.

This library handles the full BSP document workflow:

  • Build simple bids — divisible and indivisible bids with full attribute support (volume, price, resource, product type, duration constraints)
  • Technically linked bids — prevent double-activation across consecutive MTUs
  • Conditionally linked bids — adjust availability based on prior-MTU activation outcome
  • Complex bid groups — ExclusiveGroup, MultipartGroup, InclusiveGroup with group-level validation
  • TSO configuration — Statnett (NO), Energinet (DK), Svenska kraftnät (SE) fully configured; Fingrid planned
  • Validate before you send — common and TSO-specific rules, pre-MARI and post-MARI price limits
  • Serialise to CIM XML — generates compliant ReserveBid_MarketDocument XML per the NBM ReserveBid schema
  • Timing helpers — gate closure calculations, MTU boundaries, DST handling, MARI vs pre-MARI timing

This library generates and will eventually parse the XML documents you send and receive over ECP. It does not manage your ECP/EDX endpoint — that infrastructure is deployed and operated separately.

Quick start

Submit a simple bid to Statnett

from nexa_mfrr_eam import (
    Bid, BidDocument, MarketProductType,
    BiddingZone, TSO, MARIMode,
)

# Divisible up-regulation bid: 50 MW at 85.50 EUR/MWh
bid = (
    Bid.up(volume_mw=50, price_eur=85.50)
    .divisible(min_volume_mw=10)
    .for_mtu("2026-03-21T10:00Z")
    .resource("NOKG90901", coding_scheme="NNO")
    .product_type(MarketProductType.SCHEDULED_AND_DIRECT)
    .build()
)

# Wrap in a document targeting Statnett
doc = (
    BidDocument(tso=TSO.STATNETT)
    .sender(party_id="9999909919920", coding_scheme="A10")
    .add_bid(bid)
    .build()
)

# Validate against Statnett rules
errors = doc.validate(mari_mode=MARIMode.PRE_MARI)
if not errors:
    xml_bytes = doc.to_xml()
    # Send xml_bytes via your ECP endpoint

Build a multipart bid

Multipart bids offer volume at multiple price levels for the same MTU. If a higher-priced component is accepted, all cheaper components must also be accepted.

from nexa_mfrr_eam import Direction, MultipartGroup, BiddingZone, TSO, BidDocument

group = (
    MultipartGroup(bidding_zone=BiddingZone.NO2)
    .direction(Direction.UP)
    .for_mtu("2026-03-21T10:00Z")
    .resource("NOKG90901", coding_scheme="NNO")
    .add_component(volume_mw=20, price_eur=50.00)
    .add_component(volume_mw=15, price_eur=75.00)
    .add_component(volume_mw=10, price_eur=120.00)
    .build()
)

doc = (
    BidDocument(tso=TSO.STATNETT)
    .sender(party_id="9999909919920", coding_scheme="A10")
    .add_bids(group)
    .build()
)

Technically linked bids

Technical links prevent double-activation when a resource spans consecutive MTUs.

from nexa_mfrr_eam import Bid, TechnicalLink, BiddingZone, TSO, BidDocument

link = TechnicalLink()

bid_qh1 = (
    Bid.up(volume_mw=30, price_eur=60.00)
    .for_mtu("2026-03-21T10:00Z")
    .resource("NOKG90901", coding_scheme="NNO")
    .link(link)
    .build()
)

bid_qh2 = (
    Bid.up(volume_mw=30, price_eur=60.00)
    .for_mtu("2026-03-21T10:15Z")
    .resource("NOKG90901", coding_scheme="NNO")
    .link(link)
    .build()
)

doc = (
    BidDocument(tso=TSO.STATNETT)
    .sender(party_id="9999909919920", coding_scheme="A10")
    .add_bids([bid_qh1, bid_qh2])
    .build()
)

Domain notes

Market time units

The mFRR EAM operates on 15-minute MTUs (96 per day). Gate closure for BSPs is QH-45 in pre-MARI mode and QH-25 in post-MARI mode.

Price limits

Mode Limit
Pre-MARI -10,000 to +10,000 EUR/MWh
Post-MARI -15,000 to +15,000 EUR/MWh

Minimum volumes

  • General: 1 MW minimum bid
  • Statnett: 10 MW minimum (exception: one bid per resource/direction/MTU may be 5–9 MW)

MARI mode

The market will transition to the European MARI platform. The library supports both configurations via a toggle:

from nexa_mfrr_eam import configure, MARIMode

configure(mari_mode=MARIMode.PRE_MARI)   # default
configure(mari_mode=MARIMode.POST_MARI)  # for MARI transition testing
